# Flipkart Clone 🛒

This is a front-end clone of the Flipkart homepage, created using only **HTML** and **CSS**. It is a static website built for educational purposes to practice web design and layout structure. The project was developed using **Visual Studio Code**.

## 💡 Features
- Responsive layout (basic)
- Navigation bar
- Banner section
- Product cards and images

## 🛠️ Technologies Used
- HTML5
- CSS3
- Visual Studio Code

## 🚀 How to Run
1. Clone this repository.
2. Open the `index.html` file in any web browser.
